# MKM590 turbulent-channel example

The repository's [`examples/mkm590`](https://github.com/Davide-Lasagna-s-Lab/ChannelFlow.jl/tree/main/examples/mkm590)
contains a GPU Poiseuille run, restartable statistics, reference data, comparison
plots and a wall-normal/spanwise animation. Its target is the smaller-box
``Re_\tau\simeq590`` case of Moser, Kim & Mansour (1999), not the larger Lee–Moser domain.

## Configuration

| Quantity | Value |
|---|---|
| Domain | ``L_x=2\pi``, ``y\in[-1,1]``, ``L_z=\pi`` |
| Resolved points `(Nx,Ny,Nz)` | `(384,257,384)` |
| Driving | constant total bulk velocity ``U_b=1`` |
| Viscosity | about ``9.12935\times10^{-5}`` |
| Nominal timestep | `0.0025` |
| Reference friction Reynolds number | `587.19` |

The initialization is a small, smooth perturbation of the laminar profile.
Consequently the measured friction Reynolds number starts near 181, not 590.
Turbulent wall stress is an outcome of the simulation. Verify transition and
stationarity before interpreting accumulated statistics as a turbulent average.
The spatial box matches the reference; this code's CNRK2 scheme is not the
reference paper's time integrator.

## Run and restart

From the repository root, after instantiating `test/cuda`:

```sh
julia --project=test/cuda examples/mkm590/run.jl
```

Edit the clearly grouped parameters at the top of `run.jl`: resolution,
timestep, run length, averaging start, sample/checkpoint cadence and restart
flags. Set `RESTART=true` to continue the saved state. Keep numerical settings
consistent with the checkpoint. `RESET_STATS` starts a new averaging window
while retaining the flow state. A `STOP` file in the output folder requests a
clean stop; a wall-time budget also triggers checkpointing.

## Outputs and comparison

`history.csv` records time, bulk velocity, friction Reynolds number, CFL and
perturbation energy. Profile statistics contain the total mean velocity and all
six Reynolds-stress components. Checkpoints preserve velocity, stage pressure,
step number and covariance accumulators. Streamwise-velocity slices are stored
in the ``y,z`` plane at one streamwise position for animation.

Use `compare.py` for wall-unit mean-flow/stress plots and `animate.py` for the
movie and snapshot. Their Python dependencies and exact invocation are in the
[example README](https://github.com/Davide-Lasagna-s-Lab/ChannelFlow.jl/blob/main/examples/mkm590/README.md).
The example includes reference-data attribution and normalization details.

Only compare after a sufficiently long statistically stationary averaging window.
A visually turbulent snapshot does not establish convergence of mean profiles,
stresses or wall friction. No completed statistical agreement is claimed here.
